Goal

  • estimate effects of categorical and continuous predictors when the response is ordinal
  • categorical but ordered; we don’t know distances between successive levels
  • CLM = cumulative link model

## select baseline predictors (first level of each factor)
get_pframe <- function(Infl_sel = "Low",
                       Type_sel = "Tower",
                       Cont_sel = "Low") {
  subset(housing,
                 Infl == Infl_sel &
                 Type == Type_sel &
                 Cont == Cont_sel,
                 select = -c(Sat, Freq))[1,]
}

Assumptions

  • independence
  • proportional odds or equivalent: changes to predictors (change in category, or a change in a numeric variable) shifts log-odds of neighbouring categories (Medium vs Low, High vs Medium) up or down by the same amount
  • linearity of effects on this log-odds scale

Alternative links

  • logit (log-odds): proportional odds
  • probit: very similar. Interpretable as shifting the distribution of a Gaussian latent variable
